# Animenimuchu

Annict と AniList の視聴状況をユーザーと作品のグラフで可視化する．

## Usage

`/?user=annict:tosuke,annict:rinsuki,anilist:sno2wman`

## Development

```sh
bun install
echo 'ANNICT_ACCESS_TOKEN=...' > .env
bun run dev
```
