# Animenimuchu

Annict と AniList の視聴状況をユーザーと作品のグラフで可視化する．

## Usage

`/?user=anilist:sno2wman,annict:tosuke,annict:rinsuki`

## Development

```sh
bun install
echo 'ANNICT_ACCESS_TOKEN=...' > .env
bun run dev
```
